# Release Note — homegds v1.0.0

**リリース日:** 2026年7月  
**ステータス:** 正式リリース

---

## Version 1.0.0 について

家庭の食材・日用品の在庫を手軽に管理するための PWA アプリ「homegds」の初回正式リリースです。  
すべてのデータはデバイスのローカル（IndexedDB）に保存され、サーバーへの送信は一切行いません。

---

## 主な機能

### 在庫管理
- 商品の登録（商品名・カテゴリ・現在数量・単位・最低在庫・お気に入り）
- 在庫一覧（Apple設定アプリ風リスト表示）
- 横スワイプによる素早い使用 / 補充操作（数量ステップ: 0 → 0.5 → 1 → 2 → 3…）
- 長押しメニュー（編集・削除）
- ★タップによるお気に入り登録、一覧最上位表示
- 商品名での検索（リアルタイム絞り込み）
- 並び順：お気に入り → 在庫不足 → 在庫少 → その他

### ホーム画面
- 「今日補充するもの」に特化したダッシュボード
- 在庫不足・在庫が少ない商品をセクション別に最大3件表示
- 4件以上は「すべて見る」リンクへ
- 商品ゼロ時のガイド付き Empty State

### 商品詳細 / 編集
- 詳細画面での使用・補充ボタン
- 編集画面：商品名・カテゴリ・単位・最低在庫・お気に入りを変更可能
- 編集画面からの削除（確認ダイアログ付き）

### 履歴
- 追加・使用・補充・編集・削除の操作を自動記録
- 新しい順に最大100件保存（超過時は古い順から自動削除）
- 操作種別ごとの色付きラベル・変更前後の数量表示

### CSV インポート / エクスポート
- エクスポート：全商品を `homegds_YYYY-MM-DD.csv` としてダウンロード（UTF-8 BOM付き）
- インポート：CSVを選択して取り込み、重複商品は件ごとに「上書き / スキップ / 以降すべて上書き / 以降すべてスキップ」を選択
- 取り込み進捗をフェーズ別に表示（読み込み中・重複確認中・インポート中）
- 完了後に新規追加・上書き・スキップ・エラー件数を表示

### 設定画面
- 言語切替（日本語 / 繁體中文）、設定を保存して即時反映
- ダークモード（ライト / ダーク切替、設定を保存）

### デザイン・UX
- コーラルピンク × ラベンダー × スカイブルーのグラデーションアクセント
- ヘッダー・タブバー・モーダルに iOS 26 風 Glass デザイン（半透明 + backdrop-blur）
- Apple 純正アプリ風のシンプルなリスト UI（カード禁止）
- ページ遷移アニメーション（フェード + 軽いスライド、約 220ms）
- `prefers-reduced-motion` 対応（アニメーション無効化）
- iPhone Safari 対応（`-webkit-backdrop-filter`・タップハイライト除去）

### PWA
- ホーム画面への追加対応
- Service Worker によるオフラインキャッシュ（本番ビルド時）
- Web App Manifest（192×512 px アイコン、maskable 対応）

## 今後追加予定の機能（Version 1.1 以降）

| 機能 | 概要 |
|---|---|
| 在庫一覧の仮想スクロール | 1000件超でも快適に動作するよう改善 |
| 賞味期限管理 | 期限設定・期限切れ・期限間近のアラート表示 |
| 統計画面 | カテゴリ別在庫割合・消費傾向グラフ |
| バーコードスキャン | カメラで商品バーコードを読み取り自動入力 |
| 通知機能 | 在庫不足商品のプッシュ通知（PWA通知） |
| 言語切替 UI の改善 | ホーム画面からのワンタップ切替 |
| テーマカラーのカスタマイズ | ユーザーがアクセントカラーを選択可能 |

## 既知の制限事項

| 項目 | 内容 |
|---|---|
| 仮想スクロール未実装 | 商品が1000件を超えると在庫一覧のスクロールが重くなる場合があります。家庭用途（通常50〜200件）では問題ありません |
| 賞味期限のDB未保存 | CSV列として「賞味期限」は存在しますが、現バージョンではDB保存されません（インポート時は読み捨て） |
| 統計機能 | ルートは存在しますが実装は次バージョン予定です |
| オフライン初回アクセス | Service Worker が有効になるのは本番ビルド後の2回目以降のアクセスからです |
| アイコン画像 | 現在のアイコンはプレースホルダー（PNG自動生成）です。本番ではデザインデータへの差し替えを推奨します |
