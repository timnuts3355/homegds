## Version 1.1 — 実用改善リリース

**目標:** 日常的に使いながら見つかった細かい課題を解消する。新機能より「使いやすさ」を優先する。

### 不具合修正

- [ ] スワイプ操作とスクロールが競合する場合の挙動を改善
- [ ] 在庫一覧の検索バーにフォーカスした際、画面が予期せずスクロールする場合がある問題を修正
- [ ] iPhone Safari でダークモード切替時に一瞬白フラッシュが発生する場合がある問題を修正
- [ ] CSVインポートで同一ファイルを2回選択しようとすると `onChange` が発火しない場合がある問題を修正（`input`の`value`リセット）

### UI・UX の軽微な改善

- [ ] 在庫一覧：スワイプヒント（初回起動時のみ「← 使用 / 補充 →」をガイド表示）
- [ ] 商品追加フォーム：キーボードの「次へ」ボタンでフィールドを順番に移動できるよう `returnKeyType` を最適化
- [ ] 商品詳細：使用・補充ボタンのタップ時にわずかなハプティクスフィードバック（Vibration API）
- [ ] 在庫一覧：0件検索時の Empty State にアイコンを追加（現在はテキストのみ）
- [ ] 履歴画面：日付をグループヘッダー（「今日」「昨日」「MM/DD」）でセクション分けして表示
- [ ] 設定画面にアプリバージョン（`v1.0.0`）の表示を追加
- [ ] ホーム画面の「すべて見る」リンクを在庫一覧の適切なフィルター状態へ遷移させる

### 翻訳・テキスト

- [ ] 繁體中文のバリデーションエラーメッセージを翻訳（現在は日本語固定）
- [ ] CSVインポートのエラーメッセージを繁體中文に対応

## 将来検討

将来的に価値が高いと思われるが、現時点では詳細設計が決まっていない機能。

### データ・連携

- **クラウド同期** — 複数デバイス間でデータを共有する仕組み。プライバシーを優先した設計（E2E暗号化等）を前提に検討。
- **ショッピングリスト連携** — 在庫不足商品をワンタップでショッピングリスト（メモ・リマインダー）に追加。
- **家族との共有** — 同一家庭内の複数ユーザーで在庫データを共有できる仕組み。

### UI・カスタマイズ

- **ウィジェット対応** — iOS ホーム画面ウィジェットで在庫状況をチラ見（PWA の現状では制限あり）。
- **テーマカラー変更** — グラデーションの色をユーザーが選択できるオプション。
- **アイコンサイズ変更** — テキストサイズ・行の高さを設定で変更できるアクセシビリティ対応。

### 商品データ

- **商品マスタのテンプレート** — よく登録される食品・日用品のテンプレートをプリセットとして提供。
- **写真の添付** — 商品画像をカメラで撮影して登録（保存先は IndexedDB または端末ストレージ）。
